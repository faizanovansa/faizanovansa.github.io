# Faiza Novansa - Vibe Coder

A premium personal branding website built with pure HTML, CSS, and JavaScript.

**Live:** https://faizanovansa.github.io

## About

This website showcases Faiza Novansa's journey as a Visual Communication Design student learning web development, AI, and cybersecurity. The design balances developer aesthetics with creative vision, inspired by modern design systems and subtle anime atmosphere.

## Features

- **Pure Stack**: No frameworks, no build tools. Just HTML, CSS, and JavaScript.
- **High Performance**: Target 98+ Lighthouse score
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Accessibility**: Semantic HTML, ARIA labels, keyboard navigation
- **Easter Eggs**: Hidden interactions for curious explorers
- **Premium Design**: Apple × Linear × Vercel aesthetic
- **SEO Optimized**: Complete SEO implementation with meta tags, JSON-LD, sitemap

## Design Philosophy
