# Faiza Novansa - Vibe Coder Portfolio

A premium personal branding website built with pure HTML, CSS, and JavaScript. Designed to feel handcrafted, elegant, and authentically personal.

## 🎨 Design Philosophy

This portfolio balances three core identities:
- **Developer** → Technical expertise and clean code
- **Creative** → Design-focused, aesthetic-driven approach
- **Otaku** → Inspired by anime worldbuilding and atmospheric storytelling

The result is a unique vibe that feels neither generic nor cringe—just authentically Faiza.

## 🚀 Features

### Core Elements
- **Beautiful Hero Section** - Memorable headline with aurora background animation
- **Smooth Navigation** - Sticky navbar with active link highlighting
- **Responsive Design** - Mobile-first, works perfectly on all screen sizes
- **Performance Optimized** - Target 98+ Lighthouse scores
- **Accessibility First** - WCAG 2.1 AA compliant, semantic HTML

### Interactive Features
- Mouse glow effect in hero section
- Parallax scrolling on aurora background
- Smooth fade-in animations for elements
- Mobile-responsive hamburger menu
- Keyboard navigation support
- Intersection Observer for scroll animations

## 🎮 Interactive Features Explained

### Mouse Glow
The hero section features a responsive glow effect that follows your cursor, creating an engaging focal point.

### Aurora Animation
The background features a subtle, continuously-animating aurora gradient that represents the "Frieren" aesthetic inspiration.

### Parallax Scrolling
As you scroll, the aurora background moves at a different speed than the foreground, creating depth perception.

### Toast Notifications
Easter eggs trigger small, non-intrusive toast notifications that slide in from the right side.

### Smooth Scrolling
All navigation links use smooth scroll behavior, making the browsing experience feel polished.

### Active Link Highlighting
The navbar automatically highlights which section you're currently viewing.

### Fade-in Animations
Elements fade in and slide up as they come into view, using Intersection Observer for performance.
